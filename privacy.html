Privacy Policy

Last updated: 25 November 2026

What this covers

This policy covers "Old Maps Uploader", a private tool the Old Maps Decoded channel uses to publish its own videos to YouTube through the YouTube Data API. It also covers this website.

Who uses the tool

The tool is used only by the owner of the Old Maps Decoded channel, on the owner's own computer, for the owner's own channel. It is not offered to the public and does not sign in anyone else.

What data it accesses

With the owner's permission, the tool uses the YouTube scopes youtube.upload and youtube.force-ssl to upload videos, set thumbnails, add captions and update the channel's banner and description. It reads the channel's own name to confirm it is signed in to the right channel. It does not read viewers' data, comments, subscribers' details or any other Google account data.

How data is stored

The sign-in token is stored only on the owner's computer, in a file readable only by the owner. Nothing is sent to any server other than Google's. No data is sold, shared, or used for advertising or analytics.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements, and the YouTube Terms of Service.

This website

This site is hosted on GitHub Pages. It sets no cookies and runs no analytics of its own; GitHub may keep standard server logs under its own privacy statement.

Contact

Questions: contact the Old Maps Decoded channel through its YouTube page.
